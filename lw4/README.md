
### 1. Принцип роботи та області застосування SPI

SPI (Serial Peripheral Interface) — це синхронний послідовний протокол передачі даних у дуплексному режимі (Full Duplex).

* Принцип: Працює за моделлю Master-Slave (ведучий-ведений). Ведучий генерує тактовий сигнал (SCLK) і керує вибором пристрою (SS).
* Застосування: Датчики, SD-карти, дисплеї, модулі зв'язку (як ваш RC522), де потрібна висока швидкість обміну на коротких відстанях.

### 2. Апаратна структура SPI

Інтерфейс використовує 4 основні лінії:

1. SCLK (Serial Clock): Тактовий сигнал від Master.
2. MOSI (Master Out Slave In): Передача від ведучого до веденого.
3. MISO (Master In Slave Out): Передача від веденого до ведучого.
4. SS/CS (Slave Select / Chip Select): Вибір конкретного пристрою (активується низьким рівнем "0").

### 3. Часові діаграми та режими

Режим роботи визначається двома параметрами: CPOL (полярність) та CPHA (фаза).

* Mode 0: CPOL=0, CPHA=0 (дані зчитуються на передньому фронті, SCLK в спокої низький).
* Mode 1: CPOL=0, CPHA=1.
* Mode 2: CPOL=1, CPHA=0.
* Mode 3: CPOL=1, CPHA=1.

### 4. Технологія RFID: особливості та використання

RFID (Radio Frequency Identification) — безконтактна ідентифікація за допомогою радіосигналів.

* Особливості: Не потребує прямої видимості (на відміну від штрих-коду), може зчитувати через перешкоди.
* Сфери: СКУД (перепустки), логістика (облік товарів), безконтактна оплата, ідентифікація тварин.

### 5. Модуль RC522

* Характеристики: Робоча частота 13.56 МГц, напруга живлення 3.3 В, підтримка протоколів ISO/IEC 14443 A.
* Підключення: Через SPI (SDA/NSS, SCK, MOSI, MISO). Також потребує ліній RST (скидання) та живлення 3.3V (не 5V!).

### 6. RFID-мітки

Складаються з антени та мікрочіпа.

* Принцип: Рідер створює електромагнітне поле. Пасивна мітка потрапляє в поле, отримує від нього енергію (індукція), "прокидається" і передає свій ID або дані у відповідь.

### 7. Структура пам’яті MIFARE Classic 1K

* Об'єм: 1 КБ, розділений на 16 секторів (0–15).
* Сектор: Кожен має 4 блоки по 16 байт.
* Trailer Block: Останній блок кожного сектора (Block 3) зберігає ключі доступу (Key A, Key B) та права доступу (Access Bits). Сектор 0 містить унікальний UID картки (Block 0).

### 8. Алгоритм роботи з RC522

1. PCD_Init: Ініціалізація рідера.
2. PICC_IsNewCardPresent: Перевірка наявності мітки в полі.
3. PICC_ReadCardSerial: Зчитування UID мітки.
4. PCD_Authenticate: Авторизація до конкретного сектора за допомогою ключа.
5. MIFARE_Read / MIFARE_Write: Власне операції з даними.
6. PICC_HaltA: Переведення мітки в режим сну.

### 9. Запис у блок 2 сектора 3

1. Визначити номер блоку: Сектор 3 починається з блоку $3 \times 4 = 12$. Отже, блок 0 — 12, блок 1 — 13, блок 2 — 14.
2. Авторизація: Виконати `PCD_Authenticate` для сектора 3, використовуючи ключ (зазвичай заводський `0xFFFFFFFFFFFF`).
3. Запис: Викликати функцію `MIFARE_Write(14, buffer, 16)`, де `buffer` — ваші 16 байт даних.
